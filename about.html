About Perlis

Perlis is a state in northern Peninsular Malaysia, on the border with Thailand. Visitors come for its nature, local heritage, food and border-town shopping, and many pass through Kuala Perlis on the way to Langkawi.

About this project

Jelajah Perlis is an independent, static website built with plain HTML, CSS and JavaScript as a portfolio project. It is not an official tourism site.

Practical details such as fees, opening hours and access are marked To be confirmed until verified. Please check with the relevant official source before you travel.
